Full-Stack Todo App: A simple full-stack task management application built to practice frontend development, REST API integration, backend development, and database operations.

🚀 Technologies Used:

A. Frontend
1. HTML5
2. CSS3
3. JavaScript (Vanilla JS)

B. Backend
1. Node.js
2. Express.js
3. Mongoose

C. Database
1. MongoDB
   
D. API Testing
1. Postman

✨ Features

1. Add new tasks
2. View all tasks
3. Mark tasks as completed or incomplete
4. Delete tasks
5. Store tasks in MongoDB

⚙️ How to Run Locally

1. Clone this repository.
2. Navigate to the backend folder.
3. Run npm install.
4. Create a .env file and add your MongoDB connection string.
5. Run npm start.
6. Open the frontend index.html file using Live Server.

Note: Make sure MongoDB is running on your computer before starting the backend.
